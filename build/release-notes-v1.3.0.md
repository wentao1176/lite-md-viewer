## 图片插入与文档整理

- 支持在源码编辑区直接粘贴截图或剪贴板图片。
- 新增“插入图片”按钮，弹出系统文件选择框，支持同时选择多张图片。
- 首次插图自动整理为“文档名文件夹 / Markdown 文件 + images 图片目录”，图片按 `1.png`、`2.jpg` 等连续编号，保留原始格式。
- 编辑器自动切换到新文档路径，更新图片引用并保存；后续插图继续编号，后续保存和导出使用整理后的路径。
- 首次整理时复制已有本地图片并更新引用；普通相对链接同步调整，代码和公式内容保持原样。
- 支持未保存文档选择保存位置、同名目录避让、撤销图片引用和失败回滚；取消操作保留原文档。
- 修正响应式图片搬迁后的预览候选路径，以及拖入 Markdown 后的完整路径识别。

经完整测试、实际 Electron 剪贴板/文件流程与原生 PDF 导出核查。Android 暂不更新。
