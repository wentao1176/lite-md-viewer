## 数模论文版式

- 原“黑白作业”升级为“数模论文”：中文衬线字体配合 Times New Roman，12pt 两端对齐正文、首行缩进、居中标题和清晰的章节层级。
- 采用三线表、居中图注、紧凑参考文献与简洁代码清单，去除阅读器式的圆角卡片和底纹；图片与图表保留灰度输出。
- 识别摘要、关键词及中英文参考文献；PDF 摘要独立成页，使用统一 A4 页边距，公式引导段与公式尽量同页。
- 预览与独立 HTML 共用纸张宽度；已选字体和旧版风格偏好继续有效。
- 修正 PDF 公式编号的挤压，保留 align / gather / equation 自动编号及带格式的自定义编号；避免论文正文样式影响流程图标签。
- 保留长文档图片内嵌与打印前等待机制，并修正表题重排后的源码定位。

附带 `examples/modeling-paper.md` 排版样稿。通过完整测试及多轮原生 PDF 逐页检查，覆盖公式、图表、跨页长表格与多图片长文档。
